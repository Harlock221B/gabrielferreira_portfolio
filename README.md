## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido com foco em performance, escalabilidade e uma excelente experiência de usuário (UX/UI), utilizando as seguintes tecnologias:

*   **[React](https://reactjs.org/)** + **[Vite](https://vitejs.dev/)**: Para uma interface de usuário rápida e um ambiente de desenvolvimento otimizado.
*   **[Tailwind CSS](https://tailwindcss.com/)**: Para estilização utilitária, rápida e responsiva.
*   **[React Router Dom](https://reactrouter.com/)**: Para o roteamento dinâmico das páginas de Estudo de Caso dos projetos.
*   **Context API**: Gerenciamento de estado global para temas e internacionalização.

## ✨ Principais Funcionalidades

*   **Dark/Light Mode**: Suporte nativo a temas claro e escuro, com transições suaves e integração com as preferências do sistema do usuário.
*   **Internacionalização (i18n)**: Suporte completo para dois idiomas (Português e Inglês), permitindo que recrutadores globais explorem o portfólio facilmente.
*   **Páginas Dinâmicas de Projetos (Case Studies)**: Seção detalhada para cada projeto (como Finview, Road Cars Consulting, Fonação, etc.), explicando o desafio, a solução implementada e as tecnologias utilizadas.
*   **Design "Glassmorphism"**: Elementos visuais modernos com desfoque de fundo (backdrop blur) e paleta de cores futurista.
*   **Totalmente Responsivo**: Layout otimizado para funcionar perfeitamente em dispositivos móveis, tablets e desktops.

## 🛠️ Como executar o projeto localmente

Se você deseja clonar e rodar este projeto na sua máquina local, siga os passos abaixo:

### Pré-requisitos
*   Node.js instalado na sua máquina (recomendado versão 18+).

### Instalação

1. Clone o repositório:
```bash
git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
```
Acesse a pasta do projeto:

Bash
```bash
cd seu-repositorio
```
Instale as dependências:

Bash
```bash
npm install
```
Inicie o servidor de desenvolvimento local:

Bash
```bash
npm run dev
```
Abra o seu navegador e acesse http://localhost:5173.
